## About Me

I'm a data-driven analytics professional who turns messy, fragmented operational data into automated systems people actually use. At **Estée Lauder Companies India**, I independently designed and deployed a pan-India MIS tracking system from scratch — consolidating scattered manual data into automated dashboards adopted by 22+ District Managers across 5 regions, cutting reporting effort by ~85%.

My core strength is converting ambiguous business questions into structured analysis — SQL for the querying, Python for the automation, Power BI/Tableau/Excel for the storytelling. I treat AI tools like Claude as a default multiplier in my workflow, not a crutch — using them to accelerate scripting, troubleshooting, and documentation so I can focus on the actual analysis.

**🔭 Currently:** Building out personal analytics projects and preparing for graduate study in Business Analytics / Financial Engineering
**🌱 Learning:** Advanced Power Query, deeper Python automation patterns
**💬 Open to:** Data Analyst, BI Analyst, and Operations Analytics roles
